# TK2 Mod Studio

A local, readable modding workspace for The Karters 2: Turbo Charged. Initial target: **0.1.4.18 / beta_dev**, installed BepInEx **6.0.0-be.788**.

This repository will contain the investigation, implementation roadmap, Windows GUI, analysis/export scripts, and a C# starter plugin. Recovered game declarations and Ghidra pseudocode are local analysis artifacts, not original source code.

See [the roadmap](docs/ROADMAP.md), [investigation](docs/INVESTIGATION.md), and [mod possibilities](docs/CAPABILITIES.md).
