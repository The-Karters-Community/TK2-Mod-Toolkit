How reconstruction works

Seven native methods have editable C# behavior here. This is a semantic reconstruction, not the original Unity project. Jump handling assumes initialized objects and stable grounding during a call. Velocity accumulation is used by the fast-fall module; gameplay execution remains locked.

The native evidence and addresses are recorded in docs/READABLE-SOURCE.md. Complex methods still require manual analysis.
