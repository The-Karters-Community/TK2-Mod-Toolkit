    Plugin & config compatibility

    BepInEx plugins

    Other enabled plugins may patch the same game behavior. The toolkit flags them as possible conflicts; it cannot prove a conflict from a filename alone.

      Plugin configs

      Config files do not load code by themselves. Disable one only when it belongs to a plugin you are troubleshooting; its original file is kept beside it.
