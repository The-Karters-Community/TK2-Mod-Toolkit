START WITH A SMALL CHANGE

Your first mod: a kart hop

Press F9 in a local race to give your kart an extra upward impulse. The template already includes a shortcut, a configurable strength and race checks.

  1. Create the recipe

    The button creates plugins/TK2.Customization/Recipes/MyKartHop.cs and opens it in Module editor. Choose another name in the editor if it already exists.

  2. Change a readable value

    In Configure, change the default strength from 6f to 8f. The allowed range is 0–30. Configure declares settings; Tick runs while enabled; Restore undoes persistent changes when disabled. 

    _hop = config.Bind("Recipe." + Name, "UpwardVelocity", 8f,
    new ConfigDescription("Extra upward velocity.",
        new AcceptableValueRange<float>(0, 30)));

  3. Use a game function

    The template finds local karts and calls the readable adapter below. In Game API reference, choose Kart & driving and search AddVelocity to inspect the declaration and reconstructed implementation. 

    ReadableGame.AddVelocity(kart, Vector3.up * _hop.Value);

    Game API entries can be public, internal or private. The adapter is our public C# helper; a private declaration alone is not a ready-to-call recipe function. Harmony hooks must specify the complete target signature.

  4. Save, build and test

    Save C#, close the game, then choose Build & install. Start the game yourself. In Mod packs → Your recipes, enable My Kart Hop and save. Press F9 during a local race. After this first build, changing its strength or toggle needs only Save changes.

    Author builds require the .NET SDK and initialized BepInEx interop. Failed builds leave the installed DLL in place; read Compiler output for the file and line to fix.

Recipes live beside the application in plugins/TK2.Customization/Recipes. Built-in modules share source files in the parent folder. Edit here or choose Open folder and use your own editor. Save, build and install code once; tune its config live afterwards.
