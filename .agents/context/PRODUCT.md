# Product

## Register

product

## Users

Players who want to customize The Karters 2 without managing DLL files. Mod authors use the same application to edit readable C# and rebuild the pack. The user confirmed a clean racing-game direction with keyboard navigation and reduced-motion support.

## Product Purpose

Install one plugin, choose modifications, save settings, and create new modules in that plugin. Keep advanced reverse-engineering evidence available behind the workshop.

## Brand Personality

Sporty, clear, approachable. Use the supplied game artwork to establish identity without making ordinary controls harder to use.

## Anti-references

The previous dense tabbed Tk interface and an assembly debugger as the primary authoring experience.

## Design Principles

- Start with player controls; explain experimental features at their point of use.
- One pack, one installation action, one settings file.
- Give authors editable behavior with provenance beside the code.
- State compilation and runtime validation separately.

## Accessibility & Inclusion

Visible focus, labeled controls, keyboard navigation, reduced motion, readable contrast, and persistent light/dark preference. Use system preference on first launch.
