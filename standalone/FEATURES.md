# Bobby's Race Tools - Features

- **In-game camera controls:** field of view, distance, height, side offset, target height, pitch, yaw, roll and smoothing.
- **Consistent framing:** optionally keep the kart's size when changing field of view, or aim the camera toward it.
- **Individual resets:** reset one setting or restore the complete framing.
- **Live input HUD:** steering, acceleration, braking, reverse, jump/drift, boost and weapon inputs.
- **Replay input viewing:** optional recorded-input display, with your own driving inputs taking priority over opponent ghosts.
- **Customizable HUD:** position, scale and background opacity, with a desktop layout preview.
- **Fullscreen-friendly display:** controls and HUD render inside the game; the desktop app remains available separately.
- **Mouse, keyboard and controller controls:** keep driving with Camera visible, or explicitly switch to editing mode.
- **Local player selection:** automatic detection with an option to choose an active local racer.
- **Automatic settings saving** and configurable camera/HUD shortcuts.
- **Portable native Windows app:** no installation or BepInEx required; no game files or saves are changed.
- **Runtime discovery:** no fixed game offsets or game-version allowlist. Changes to game internals can still require an update.

Controller support uses XInput. Standalone ghost playback and split-screen behavior have not yet been validated in a live session.
